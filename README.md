# ☕ ARA Coffee - POS & Accounting System

سیستم صندوق فروشگاهی و حسابداری کافه ARA Coffee

## ✨ ویژگی‌ها
- 🛒 صندوق فروش (POS) کامل
- 📦 مدیریت محصولات و دسته‌بندی‌ها
- 📋 تاریخچه سفارشات و فاکتورها
- 📊 داشبورد و گزارشات مالی
- 🖨️ پشتیبانی از چاپگر حرارتی
- 📱 PWA - قابل نصب روی موبایل و دسکتاپ
- 🌙 حالت تاریک و روشن
- 💾 بکاپ و بازیابی اطلاعات
- 📥 خروجی Excel و PDF
- 🔄 همگام‌سازی با GitHub

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- مرورگر مدرن (Chrome، Firefox، Safari، Edge)
- سرور استاتیک (Live Server، Python HTTP Server و...)
